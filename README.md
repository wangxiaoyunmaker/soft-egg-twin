# Soft Egg Twin · 手心里的蛋蛋

基于原有 Three.js / WebGPU 软蛋项目，加入**黄色蛋轮廓追踪 + 双手动作识别 + 多区域 USB 压力输入**。手里的黄色蛋移动、在画面内倾斜摇摆时，屏幕里的蛋同步跟随；当前主要交互为拍头、摸头、双手托举，分别对应惊讶、闭眼享受、安心微笑；多区域 USB 压力仍可驱动局部形变。

默认进入「实体连接」模式。没有硬件时可以开启摄像头，用双手动作驱动反馈，也可使用区域滑块和「拍头 · 惊讶 / 摸头 · 享受 / 双手托住 · 安心」示例；「鼠标实验室」保留原来的抓取、回弹、不倒翁和勺子交互。

## 本地启动

```bash
# Node.js 24，pnpm 11
pnpm install --frozen-lockfile
pnpm dev
```

打开终端给出的 localhost 地址。需要支持 **WebGPU** 的浏览器；**USB 串口请使用桌面 Chrome / Edge**。摄像头需要 localhost 或 HTTPS，点击按钮后由浏览器请求权限。

首次启动/构建会下载固定版本的 MediaPipe 手部模型，校验 SHA-256，并把 npm 包内的 WASM 复制到本地静态目录。下载完成后摄像头模型无需 CDN；视频与压力数据在浏览器内处理，不上传服务器。模型下载地址需网络可达。不要直接双击 `index.html`。

## 怎么用

1. 先点「拍头 · 惊讶 / 摸头 · 享受 / 双手托住 · 安心」，或拖动六个示例区域滑块，查看反馈。
2. 点「开启摄像头」，先让黄色蛋露出轮廓，等金框锁定，再点「当前位置归中」（仅归中位置与大小，倾斜始终按画面竖直方向）。最多检测两只手，绿色定位手/桃色另一只手用于显示角色；三种动作判断会检查全部可见手，不要求拍头手属于固定颜色。
   - **拍头 → 惊讶：** 一只动作手从蛋上方短促落下，接近头部后再抬起。可由另一只手托蛋，也可将蛋固定在桌上。
   - **摸头 → 享受：** 手指沿蛋的上端连续轻扫，来回移动，闭眼微笑。
   - **双手托举 → 安心：** 两只手从蛋的两侧或下方包住、彼此分开并稳定托抱至少约 260 ms；两只手仅仅可见不算托举。表情柔和、微笑更明显，不生成挤压强度。
   识别不到黄色蛋时，点击预览中蛋的黄色部分（避开高光、手指），或在「蛋的追踪与校准」恢复默认黄色。可以关闭「跟随黄色蛋的位置与倾斜」，仍保留头部动作识别。遮挡严重时可点「标记蛋头」，再点击蛋最上端；蓝圈应覆盖实际蛋头，换手或移动后需重新标记，点击「恢复自动定位」重新使用黄色轮廓。识别到错误动作后可点「重置动作识别」，不再依赖自然握姿的收拢基线。
3. 在「测点与校准」导入你们的测点配置。默认六区、12 位 ADC（0–4095）只是示例，并不意味着硬件已匹配。
4. 点「连接 USB 串口」，选设备；串口占用时先关闭 Arduino 串口监视器。连接后区域滑块变成硬件读数。
5. 轻握实体蛋，点「以当前握持校零」。配置保存在当前浏览器本地，也可导出。
6. USB 连接时局部形变以传感器为准，摄像头继续追踪蛋的位置、倾斜和三种交互表情。断开后，若「识别拍头、摸头和双手托举」已勾选且摄像头运行，则恢复手势反馈；否则使用模拟输入。点示例动作会暂时预览表情，结束后自动恢复视觉驱动。切到鼠标实验室或离开页面会关闭摄像头和串口。

## 卡顿诊断

实体连接侧栏底部展开「运行诊断与日志」，可查看帧率、可用的 JS 堆读数和本地服务连接状态，点击「导出诊断日志」下载 JSON。刷新后再导出也会保留此前记录；上限 240 条，每 5 秒一次性能汇总，并记录报错、长任务、渲染停顿、摄像头启动阶段、视频轨道事件、模型耗时、热更新和服务失联。

日志不记录摄像头图像、录音、手部关键点或原始压力包。`hand.worker` 是后台手部检测耗时（旧版 `hand.inference` 在主线程）；`interactionDiagnostics` 记录头部候选位置、轨迹跨度、采样间隔与未触发原因；`headSource` 区分自动定位、短暂遮挡参考与手动参考；`physics` 是软体物理；`surface` 是表面更新；`render.submit` 是 JavaScript 提交耗时，不是 GPU 实际执行时间。JS 堆也不包含全部 WASM、视频、GPU 或浏览器进程内存，不能单凭它判定内存泄漏。

开发服务在 `.diagnostics/server.log` 自动记录启动、输出、每 15 秒的内存与连通状态、退出代码和终止信号。日志超过 2 MB 轮转，保留当前与上一份，目录不进 Git。`.diagnostics/launcher-output.log` 用于启动排错。普通 `pnpm dev` 在终端前台运行；希望服务独立于终端/对话会话时运行：

```bash
pnpm dev:background
```

固定使用 5174 端口，已存在有效服务时不重复启动。后台服务不会自动重启电脑或注册开机启动。摄像头请求 15 秒、播放 10 秒、后台模型 45 秒、单次推理 10 秒超时后会提示并清理资源；超过期限才返回的摄像头流/模型也会关闭。

主线程完全阻塞期间日志计时器也不能执行，只能在恢复后记录长任务和帧间隔；浏览器或系统被强制终止时，最后几秒和终止原因可能没有留下记录。此前实物追踪丢失、换握姿导致动作误判仍需用新三动作规则进一步验证，不等同于页面崩溃。

## USB 协议

**115200 baud；UTF-8；每行一个完整 JSON，以 `\n` 结束。建议约 50 Hz。** 每帧必须包含配置中的全部测点；可以按 id 命名，也可以按配置顺序发数组。

原始 ADC 值：

```json
{"pressure":{"top":120,"left":580,"front":1100,"right":650,"back":90,"base":100},"normalized":false}
```

或由固件完成归一化：

```json
{"pressure":[0.05,0.2,0.8,0.2,0,0],"normalized":true}
```

`normalized` 默认为 `false`。原始值按每区 `(value - baseline) / (maximum - baseline)` 处理，裁剪到 0–1。归一化包必须已经在 0–1，且不能使用原始值校零。压力值应随受力增大；反向电路应在固件中转换。

- [12 位示例配置](examples/sensors-12bit.json)
- [Arduino Uno/Nano 10 位示例配置](examples/sensors-arduino-10bit.json)
- [Arduino USB 示例固件](hardware/egg_pressure_usb.ino)：A0–A5 → top / left / front / right / back / base；未针对你们的实际电路编译或烧录。
- [数据包示例](examples/pressure.ndjson)
- [接线、配置与识别边界](docs/hardware.md)

默认 750 ms 没收到有效完整帧，动作状态回到等待、压力形变逐渐释放。错误 JSON、缺测点、非数值和超长行被丢弃。断开连接会清除当前输入，防止一直“被捏住”。

## 测点配置

支持 1–32 个测点，每区包含 `id`、`label`、`position`、`baseline`、`maximum`。`position` 是蛋本地坐标：x/z 为 -1～1，y 为 0～1，程序映射到最近的表面点。默认正面大致朝向 +z。测点随数字蛋一起倾斜，但纯色轮廓不能识别绕长轴的自转；实体测点与屏幕区域的前后对应仍需固定初始握姿，不能视为完整三维姿态配准。

`baudRate` 和 `staleMs` 也在配置里。导入配置前先断开串口。测点名称仅作为文本展示。

## 反馈与能力边界

- **蛋体位置与倾斜：** 在 320 像素宽的摄像头帧中用黄色 HSV 范围分割连通区域，结合两只手附近范围、形状和前帧连续性选择目标。连续三帧锁定后，用轮廓中心驱动屏幕平移，像素空间主轴（PCA）相对画面竖直方向驱动倾斜（约 ±90°），3° 内的小偏差视为直立，长轴大小比例驱动 0.7–1.4× 的视觉大小。可关闭「同步摇摆」保持直立，移动与动作识别继续运行。金框与轴线显示实际选中的区域；可点选黄色采样校色，运算留在本机。
- **姿态边界：** 这是单目颜色/轮廓启发式，尚未在用户实物上标定。画面内倾斜与摇摆可跟随；纯色蛋绕长轴的自转、前后翻转和真实三维深度不能可靠恢复。大小是视觉近似，俯仰、捏变形和部分遮挡也可能改变它。接近圆形时短暂保留倾斜；轮廓失踪超过 400 ms 时保持位置与大小，超过 1 秒没有可靠角度则缓慢回正（显示后备，非实测姿态）。大幅角度变化需要三帧确认，明显变短的残缺轮廓不直接改变倾斜；重获连续三帧后按画面竖直基准恢复倾斜，无法辨认遮挡期间是否转了 180°。相似黄色背景、肤色偏黄或复杂遮挡仍可能误识别。
- **双手与位置后备：** MediaPipe 最多追踪两只手，根据空间连续性和左右手标签保留角色。蛋体尚未锁定或手动关闭蛋体追踪时，托蛋手掌心作为位置代理；托蛋手消失时保持位置，不自动换到触碰手。可手动交换托蛋手。关闭蛋体追踪会恢复直立和固定大小。
- **形变：** 多测点压力映射为有界的局部表面凹陷，叠加在原有软体表面上；松开后平滑恢复，局部暖色提示接触。该层是艺术化反馈，未标定为牛顿、毫米或真实外壳形变；原实验室的物理体积读数不代表这层视觉形变。
- **传感器动作：** 高局部压力 → 捏；多个区域持续高压 → 握紧；三个相邻区域的低压连续转移 → 抚摸候选。阈值为原型启发式，未在真实用户/传感器上验证。重新握持、外壳受力串扰可能被误判为抚摸。
- **三种视觉交互：** 把黄色轮廓的上端当作头部，各只手分别维护连续轨迹。拍头从多帧下降中判断，在头部附近有足够下降速度时触发 650 ms 惊讶，需要抬起后再拍；摸头使用至少三帧、240 ms 的头部附近累计行程，允许弧线与斜向移动；双手托举要求两掌分开、平均位于蛋中心以下、贴近两侧或下方并持续至少 260 ms。蓝圈显示头部参考，诊断显示未定位、范围之外或移动不足等原因。短暂遮挡时参考随托蛋手平移，自动参考最多保留 1.2 秒；严重遮挡时可「标记蛋头」，手动参考需在移动或换手后重新校准。间隔超过 900 ms 清除轨迹；拍头的下降不能跨越超过 600 ms。反馈在 400–900 ms 未更新时释放，随采样间隔调整。两手与蛋整体平移不会作为摸头轨迹。所有判定仍是未经过真人标注评估的启发式，不能确认真实接触、力度或手心朝向；误触发和漏检仍需实物复测。
- **表情优先级：** 拍头为惊讶，摸头为闭眼享受，双手托举为安心微笑。三者的表情独立于 USB 的实际压力，因此托举时测点有压力不会自动把安心表情改成挤压表情。未检测到三种动作时，仍允许鼠标实验室和压力输入的原有表情反馈。
- **摄像头：** MediaPipe 双手模型运行在 Web Worker，优先 GPU，失败后在后台回退 CPU。输入缩至 384 像素宽，最多一帧在途，避免累积帧队列；蛋轮廓使用同一帧的 320 像素图像。主画面继续渲染，日志分别报告后台推理与物理计算。吞吐量取决于硬件；空白帧测试不代表握蛋遮挡场景的速度或准确率。
- **硬件：** 已实现 Web Serial 接入与断线处理，自动测试使用模拟串口流。实际传感器、串口权限、摄像头实拍与固件尚需现场联调。

## 开发与验证

```bash
pnpm test
pnpm typecheck
pnpm build
pnpm preview
```

自动测试覆盖原有软体行为，以及压力包完整性、分包/超长包、独立校零、断流释放、动作区分、追踪丢失、有界形变、表情和串口生命周期，以及双手角色稳定、拍头/摸头/托举、历史按压/捏握规则、整体平移抑制和遮挡恢复。GitHub Actions 自动执行测试和构建。

GitHub Pages 工作流只支持手动触发；此仓库默认私有，未开启公共站点。`.openai/hosting.json` 不用于本项目，以免误连接原模板的托管身份。

## 代码入口

- `src/twin/controller.ts`：交互模式、压力源、连接状态与 UI。
- `src/twin/pressure.ts`：协议解析、归一化、滤波和动作判断。
- `src/twin/camera.ts` / `tracking.ts`：双手摄像头检测、稳定角色与位置映射。
- `src/twin/egg-tracking.ts`：黄色像素分割、轮廓关联、平移/倾斜/大小映射与遮挡保持。
- `tests/browser/egg-motion.html`：生成黄色像素后经过真实检测器、控制器、WebGPU 的回放，不开启摄像头。
- `src/twin/egg-interactions.ts`：相对蛋头的拍头、摸头与双手托举判断。旧 `vision-gestures.ts` 保留历史实验规则，当前默认页面不使用它。
- `tests/browser/three-interactions.html`：三种动作 → 完整控制器 → 实际 WebGPU 表情回放，不开启真实摄像头、不代表识别准确率。旧双手回放入口指向此页。
- `src/twin/deformation.ts`：测点到蛋表面形变与触碰高亮。
- `src/scene/world.ts` / `face.ts`：原软蛋场景和表情，接入新反馈。

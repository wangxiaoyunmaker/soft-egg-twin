## 三种交互与表情增量

- 当前页面以 `EggInteractions` 替代旧的自然握姿收拢判断：从上方短促拍头 → 惊讶，头部连续轻扫 → 闭眼享受，两掌在蛋下方分开且持续托举 → 安心微笑。视觉反应不再被握紧基线误判挡住。
- 新增 7 个行为测试覆盖短拍/重新抬手、轻扫/静止/侧面排除、双手稳定托举/远处手排除、整体平移、遮挡与身份变化、单手动作和三种表情优先级。相关压力、旧算法与原表情回归检查通过，构建与类型检查通过；未重跑全部物理长测试。
- `/tests/browser/three-interactions.html` 使用生成的黄色视频帧和合成双手轨迹，通过实际轮廓检测、控制器和 WebGPU，分别观察到 `pat → surprised`、`headStroke → soothed`、`cradle → cherished`。其中托举反馈强度为零，独立显示安心表情。
- 当前三个新手势尚未经过用户实物现场验证。头部由画面长轴上端近似；纯色蛋翻转、手心朝向不可见、遮挡或帧率不足都可能造成误判或不识别。

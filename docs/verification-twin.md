## 双手与视觉动作增量

- MediaPipe `numHands=2`，保留全部手部结果；绿色托蛋手/桃色触碰手，支持手动交换角色和自然握姿校准。
- 39 个测试通过：新增双手检测排序变化、交叉、长遮挡、手势基线、收紧/按压/切向抚摸、整体平移抑制、静止接触和快速跳变等检查。
- 浏览器合成轨迹回放通过完整控制器和真实 WebGPU 场景，分别观察到 `2 hands / press`、`2 hands / stroke` 和 `2 hands / hold`；托蛋手消失后动作释放且角色不自动换人。
- 回放页 `/tests/browser/two-hands.html` 明确标记为合成输入，不调用真实摄像头。它验证交互管线，不证明真人动作识别准确率。
- USB 接入时压力反馈仍由传感器决定，视觉驱动仅在未连接 USB 且开关启用时生效。摄像头的动作估计不声明实测压力。

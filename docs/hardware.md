# 实体蛋接入

## 数据链路

压力测点 → 微控制器 ADC → USB 串口（115200）→ 浏览器 Web Serial → 独立校准/滤波 → 数字蛋表面与表情。

摄像头 → 黄色轮廓分割 + 双手关键点 → 蛋的二维位置、画面内倾斜、轮廓大小 + 触碰动作候选 → 数字蛋姿态与反馈。

黄色蛋首次锁定前，托蛋手位置作为后备。锁定后轮廓丢失会保持姿态；不从手部动作猜测不可见的蛋体旋转。绕长轴自转与真实三维深度尚不可测，详见 README 的能力边界。

摄像头只在用户点按钮后开启。传感器与摄像头互相独立：可以只用压力、只用位置，也可以同时使用。

## 固件示例

`hardware/egg_pressure_usb.ino` 面向经典 5V Arduino Uno/Nano 的六路模拟输入。每个压力传感器需要符合其规格的分压或信号调理电路；不能直接把两个裸引脚当成独立模拟电压。A0–A5 顺序与示例配置一致。输入应随压力增加而增大。阻值、供电、电压范围由实际传感器/板卡确定，这里没有假定你们的传感器型号。

示例发送 0–1023 原始 ADC 值。先导入 `examples/sensors-arduino-10bit.json`；12 位板卡使用 `examples/sensors-12bit.json` 并自行调整引脚。各路真正的最大可用读数通常不等于 ADC 满量程，可在配置中逐区调整 `maximum`。

1. 烧录与你们板卡匹配的固件。
2. 在串口监视器确认每行 JSON 完整且全部测点都有数值；随后关闭监视器。
3. 在 Chrome/Edge 打开本地页面，导入配置，连接串口。
4. 自然握持后校零。逐区轻压/重压，检查同名滑块和蛋表面是否对应。
5. 一次测试一个动作，记录换握姿、握紧和抚摸之间的混淆，随后调整测点布局或阈值。

## 原型阈值

归一化压力低于 0.035 视为无输入，时间平滑速率为 18/s。峰值超过 0.38 进入捏；至少两区超过 0.28 并持续 0.55 s，在高峰值条件下进入握紧。单区配置不能区分局部捏和广泛握持。

抚摸候选要求低峰值、最多两区超过 0.12，且 1.4 s 内有至少三个不同区域的主压力依次转移，路径跨度超过 180 ms。相邻性用配置位置的距离判断（y 乘 2，与蛋的大致高宽比例一致），阈值 1.25。高压和断流会清除抚摸历史。

这些是可调的实现规则，不是动作识别准确率承诺。软外壳把压力传到多个测点时，必须实测其空间和时间响应。

## 现场验收清单

- 全部区域静止时不漂移；自然握持校零后不会持续触发。
- 分别压每个测点，观察屏幕中对应区域；检查固定握持方向。
- 轻捏、长握和相邻轻扫的反馈符合预期；重新握持不频繁误报抚摸。
- 拔出 USB 或停止发送超过 750 ms，反馈释放；重新连接可恢复。
- 黄色蛋露出轮廓时，金框跟随正确物体；移动、画面内倾斜与摇摆映射方向一致。
- 检查黄衣服、暖光、部分遮挡是否误识别；必要时点选颜色、关闭大小跟随。
- 完全遮挡后姿态保持；重新露出轮廓可恢复；单独移动触碰手不会抢走托蛋手身份。
- 切换模式、关闭页面后摄像头指示灯熄灭，串口不再占用。

以上需要实际硬件与摄像头现场验证；代码测试不会替代这些检查。
